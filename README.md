This repository contains practical Jupyter notebooks, datasets, and exercises for **ML6402 – Machine Learning**.

## Practical approach

Each practical follows the same learning pattern:

**Concept → Dataset → Guided Implementation → Interpretation → Student Exercise → Challenge**

The notebooks are designed to run locally with **Anaconda/Jupyter Notebook** and can also be opened in **Google Colab**.

## Running with Anaconda

1. Install Anaconda or Miniconda.
2. Clone this repository.
3. Open Anaconda Prompt in the repository folder.
4. Create the course environment:

```bash
conda env create -f environment.yml
```

5. Activate it:

```bash
conda activate ml6402
```

6. Start Jupyter:

```bash
jupyter notebook
```
